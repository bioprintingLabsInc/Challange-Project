GSE140843 — Healthy Human iPSC-Derived Cerebral Organoids

GEO Accession: GSE140843

GEO Link: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE140843

Dataset Category: Control brain organoid RNA-seq 

Organism: Homo sapiens

Model: Human iPSC-derived cerebral organoids

RNA Sequencing: Bulk RNA-seq

Experimental Condition

Healthy untreated cerebral organoids.
No chemical treatment or developmental neurotoxicity compound exposure was applied to the samples included in this control dataset.

Samples
	•	11 healthy untreated control samples
	•	11 total bulk RNA-seq samples

Control Classification

All samples included in this dataset are classified as healthy untreated controls.

This dataset is intended to provide baseline human cerebral organoid gene-expression data for comparison with chemically exposed and patient-derived datasets.

Repository Contents

processed/
Processed bulk RNA-seq expression data downloaded from GEO.

metadata/
SRARunTable.csv
Original sequencing-run metadata downloaded from the NCBI SRA Run Selector.
samples_to_use.csv

Curated project metadata describing the 11 healthy control samples included in this dataset.

Raw Sequencing Data

Raw sequencing reads are available through NCBI SRA and are not stored directly in this GitHub repository.

Intended Project Use

Healthy human cerebral organoid reference dataset for establishing baseline gene-expression 
profiles for the ML-based transcriptomic developmental neurotoxicity pipeline.

Important Notes
	•	Human cerebral organoids
	•	Human iPSC-derived model
	•	Bulk RNA-seq
	•	11 healthy untreated control samples
	•	No chemical exposure
	•	No DNT-positive or DNT-negative compound treatment
	•	Intended to serve as a baseline control dataset for comparison with DNT-exposed brain organoids and patient transcriptomic data



GSE250142 — Healthy Untreated Human Cortical Brain Organoids

GEO Accession: GSE250142

GEO Link: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE250142

Dataset Category: Control brain organoid RNA-seq

Organism: Homo sapiens

Model: Human iPSC-derived cortical brain organoids

RNA Sequencing: Bulk RNA-seq

iPSC Lines

* 01B
* 043A
* 250A

Experimental Condition: Healthy untreated cortical brain organoids.

No chemical treatment or developmental neurotoxicity compound exposure was applied to the samples included in this control dataset.

Developmental Time Points

* Day 26
* Day 46
* Day 61

Samples

* 8 healthy untreated control samples
* 8 total bulk RNA-seq samples

Control Classification

All samples included in this dataset are classified as healthy untreated controls.

This dataset is intended to provide baseline human cortical brain organoid gene-expression data for comparison with chemically exposed and patient-derived datasets.

Repository Contents

processed/

`GSE250142_gene_count_matrix_control.csv`

Processed bulk RNA-seq raw gene-count matrix downloaded from GEO.

metadata/

`SRARunTable.csv`

Original sequencing-run metadata downloaded from the NCBI SRA Run Selector.

samples_to_use.csv

Curated project metadata describing the eight healthy control samples, including iPSC line, developmental time point, tissue, treatment status, and control classification.

Raw Sequencing Data

Raw sequencing reads are available through NCBI SRA and are not stored directly in this GitHub repository.

Intended Project Use

Healthy human cortical brain organoid reference dataset for establishing baseline gene-expression profiles for the ML-based transcriptomic developmental neurotoxicity pipeline.

Important Notes

* Human cortical brain organoids
* Human iPSC-derived model
* Bulk RNA-seq
* 8 healthy untreated control samples
* Three independent iPSC lines
* Includes Day 26, Day 46, and Day 61 developmental stages
* No chemical exposure
* No DNT-positive or DNT-negative compound treatment
* Intended to serve as a baseline control dataset for comparison with DNT-exposed brain organoids and patient transcriptomic data
